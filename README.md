# Силовые дома — PWA

Версия приложения «Силовые дома» для публикации в интернете: устанавливается на домашний экран телефона,
запускается без адресной строки и работает офлайн.

**Публичная версия содержит только тренировки: три вкладки — «Сегодня», «Упражнения», «Дневник».**
Раздел «Безопасность», упоминания лекарств, операции и врачей из этой сборки удалены на этапе сборки
(`.preview/pwa/build-pwa.mjs`), а не спрятаны в интерфейсе. Полная версия с медицинским разделом
остаётся только в локальном архиве и не публикуется.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Приложение без медицинского раздела плюс PWA-теги, `viewport-fit=cover`, отступ под вырез и регистрация сервис-воркера |
| `manifest.webmanifest` | Имя, цвета, режим `standalone`, иконки |
| `sw.js` | Кэш приложения и офлайн-режим |
| `icons/` | 192, 512, maskable-512 и apple-touch-180 |
| `serve.mjs` | Локальный сервер для проверки (без зависимостей) |

## Проверить на компьютере

```bash
cd силовые-дома-pwa
node serve.mjs
```

Откройте `http://localhost:8080`. На `localhost` сервис-воркер работает: в DevTools → Application видно
манифест, иконки и активный воркер. Проверка офлайна: DevTools → Network → Offline → перезагрузить —
страница должна открыться.

## Выложить в интернет

Установка на телефон требует HTTPS: без него браузер не включит сервис-воркер.

**GitHub Pages**

1. Создайте репозиторий и загрузите содержимое этой папки так, чтобы `index.html` лежал в корне репозитория.
2. Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
3. Через минуту адрес вида `https://<логин>.github.io/<репозиторий>/`.

**Netlify Drop** — перетащите папку целиком на `app.netlify.com/drop`, получите HTTPS-адрес сразу.

## Установка на телефон

- **iPhone (Safari):** открыть адрес → кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
  Запускать только с иконки: в режиме `standalone` нет адресной строки, а отступы под вырез и домашний
  индикатор уже учтены.
- **Android (Chrome):** меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Обновления

Поменяли `index.html` — увеличьте `VERSION` в `sw.js` (`v1` → `v2`). Старый кэш удалится при следующем
запуске. iOS иногда держит старую версию до полного закрытия приложения из переключателя задач.

## Данные

История лежит в `localStorage` под ключом `lk-strength-v1` и привязана к адресу сайта:
смена домена или очистка данных сайта стирает дневник. Синхронизации между устройствами нет.
Для резервной копии можно раз в месяц открывать дневник и переписывать цифры, либо вернуться
к варианту артефакта Claude, где состояние сохраняется в версиях файла.

## Шрифт

Manrope подгружается с Google Fonts и после первого запуска кэшируется сервис-воркером. Первый запуск
без интернета невозможен, дальше приложение работает офлайн. Если нужен полностью автономный вариант —
положите `woff2` в папку и замените `<link>` на `@font-face`, скажите, соберу.

## Что проверено

Chrome (headless), в том числе на живом адресе GitHub Pages: манифест читается без ошибок, установка
не выдаёт замечаний, сервис-воркер активируется, страница открывается при выключенной сети, иконки
отдаются с корректными размерами. В публичной сборке нет слов «Амлодипин», «Нолипрел», «тадалафил»,
«эндокринолог», «уролог», «тирзепатид», «операция», «лекарства» — сборка падает с ошибкой, если они появятся.

## Как обновить сайт

Файлы этой папки лежат в репозитории `leokravec69/Zdorovie`, сайт собирается из ветки `main`
(GitHub Pages). После правок: поднять `VERSION` в `sw.js`, закоммитить и запушить — через полминуты
обновится `https://leokravec69.github.io/Zdorovie/`.
